# Working on this testbench

This repository is published publicly on GitHub. Every file you write here must be
fully commented in English: a header comment per file (purpose, how to run it),
a comment per function (what it does, inputs, outputs), and a comment on every
non-obvious choice (why this threshold, why this method, what was rejected).

The author's private working notes (French) live in `md/`, which is git-ignored.
If it exists, read it first:

@../md/regles.md
